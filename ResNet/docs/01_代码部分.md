## Phase 2：读懂结构

### 2.1 ResNet 家族速查（ImageNet-1k，官方实现实测）

| depth | block | 每个 stage 的 block 数 | backbone 参数 | +1000 类 head | backbone 键数 | FLOPs | ImageNet top-1 |
| :-: | :--- | :--- | :-: | :-: | :-: | :-: | :-: |
| 18 | BasicBlock | 2, 2, 2, 2 | 11.18 M | 11.69 M | 120 | 1.82 G | 69.90 |
| 34 | BasicBlock | 3, 4, 6, 3 | 21.28 M | 21.80 M | 216 | 3.68 G | 73.62 |
| 50 | Bottleneck | 3, 4, 6, 3 | 23.51 M | 25.56 M | 318 | 4.12 G | 76.55 |
| 101 | Bottleneck | 3, 4, 23, 3 | 42.50 M | 44.55 M | 624 | 7.85 G | 77.97 |
| 152 | Bottleneck | 3, 8, 36, 3 | 58.14 M | 60.19 M | 930 | 11.58 G | 78.48 |

> 这组数字是**官方 `ResNet` 随机初始化后实测**的，不是抄论文。`+1000 类 head` = backbone + `2048×1000` 全连接
> （18/34 是 `512×1000`）。后面对齐时，参数量差 0.01M 都说明通道数或 block 数写错了。
>
> 小提示：官方 `metafile.yml` 里 ResNet-34 的 `Parameters: 2180000` 是**笔误**（少了一位数），
> 实测 backbone 21.28M + head 0.513M = **21.80M**，以本表为准。

### 2.2 ResNet-50 结构表（224×224 输入）

| stage | 操作 | 输出通道 | 输出尺寸 |
| :--- | :--- | :---: | :---: |
| stem | `7×7/2 conv 64` + BN + ReLU，`3×3/2 maxpool` | 64 | 56×56 |
| layer1 | 3 × Bottleneck（输入 64 → 输出 256，stride 1） | 256 | 56×56 |
| layer2 | 4 × Bottleneck（输入 256 → 输出 512，第一个 stride 2） | 512 | 28×28 |
| layer3 | 6 × Bottleneck（输入 512 → 输出 1024，第一个 stride 2） | 1024 | 14×14 |
| layer4 | 3 × Bottleneck（输入 1024 → 输出 2048，第一个 stride 2） | 2048 | 7×7 |
| neck | GlobalAveragePooling | 2048 | 1×1 |
| head | LinearClsHead：`fc 2048→1000` | 1000 | 1000 |

ResNet-18/34 把 Bottleneck 换成 BasicBlock，stage 输出通道是 **64/128/256/512**：

| stage | ResNet-18 | 输出通道 | 输出尺寸 |
| :--- | :--- | :---: | :---: |
| layer1 | 2 × BasicBlock（64→64，stride 1） | 64 | 56×56 |
| layer2 | 2 × BasicBlock（64→128，第一个 stride 2） | 128 | 28×28 |
| layer3 | 2 × BasicBlock（128→256，第一个 stride 2） | 256 | 14×14 |
| layer4 | 2 × BasicBlock（256→512，第一个 stride 2） | 512 | 7×7 |

### 2.3 两种残差块

**BasicBlock（18/34）**：两个 3×3 卷积。

```
out = conv3x3(ReLU(BN(conv3x3(x))))
out = out + shortcut(x)
y   = ReLU(out)
```

**Bottleneck（50/101/152）**：1×1 降维 → 3×3 → 1×1 升维，expansion = 4。

```
out = conv1x1(ReLU(BN(conv1x1(x))))          # C -> C/4
out = conv3x3(ReLU(BN(...)))                 # C/4 -> C/4，stride 在这里
out = conv1x1(BN(...))                       # C/4 -> C
out = out + shortcut(x)
y   = ReLU(out)
```

关键点：

- **stride 放在 Bottleneck 的 3×3 卷积上**（`style="pytorch"`）；`style="caffe"` 才放在第一个 1×1 上。
  本项目和官方默认都是 `pytorch`。
- **所有卷积 `bias=False`**：后面紧跟 BN，bias 会被 BN 的 β 吸收；带 bias 反而多参数、还会让 `state_dict` 对不上。
- **shortcut 不是恒等时**（stride ≠ 1 或通道数变化），用 `1×1 conv + BN` 把维度对齐；不是用 padding 补零。

### 2.4 downsample 什么时候出现

`ResNet` 里每个 stage 的 `out_channels` 是**扩展后**的通道数（BasicBlock 的 expansion=1，Bottleneck 的 expansion=4）。
`downsample` 的条件只有一句：

```python
if stride != 1 or in_channels != out_channels:
    downsample = nn.Sequential(
        build_conv_layer(conv_cfg, in_channels, out_channels, 1, stride=stride, bias=False),
        build_norm_layer(norm_cfg, out_channels)[1],
    )
```

ResNet-50 的四个 stage：

| stage | block 输入 | block 输出 | 第一个 block 的 stride | 有 downsample？ | bottleneck 中间通道 |
| :--- | :-: | :-: | :-: | :-: | :-: |
| layer1 | 64 | 256 | 1 | ✅（64 ≠ 256） | 64 |
| layer2 | 256 | 512 | 2 | ✅ | 128 |
| layer3 | 512 | 1024 | 2 | ✅ | 256 |
| layer4 | 1024 | 2048 | 2 | ✅ | 512 |

> layer1 的 stride=1 但**仍然有** downsample，因为输入 64、输出 256。很多人只判断 `stride != 1`，
> 结果 layer1 的 shortcut 形状对不上，前向直接报 `The size of tensor a (256) must match ... (64)`。

### 2.5 分类器在 head，不在 backbone（和 VGG 最大的区别）

```
ImageClassifier
├── data_preprocessor : ClsDataPreprocessor（归一化）
├── backbone          : MyResNet —— 输出 tuple((B, 2048, 7, 7),)
├── neck              : GlobalAveragePooling —— (B, 2048)
└── head              : LinearClsHead —— fc 2048→num_classes，输出 (B, num_classes)
```

对比 VGGNet：

| 项 | VGG16 | ResNet-50 |
| :--- | :--- | :--- |
| 分类层位置 | `backbone.classifier`（3 层 FC） | `head.fc`（1 层 Linear） |
| `num_classes` 写在哪 | `backbone.num_classes` | `head.num_classes` |
| 官方权重里的分类键 | `backbone.classifier.6.weight` | `head.fc.weight` |
| 2 类时尺寸不匹配的键 | `backbone.classifier.6.*` | `head.fc.weight` / `head.fc.bias` |
| backbone 输出 | `num_classes>0` 时直接给 logits | 永远给特征图，分类交给 head |
| 参数量 | 138.36 M | 25.56 M |
| 归一化层 | 可选（VGG-BN） | 每个卷积后都有 BN |

> 这是 ResNet 迁移学习最容易照搬错的地方：**不要给 backbone 传 `num_classes=2`**，它没有这个参数；
> 也不要去 backbone 里找 `classifier`。2 类信息全部在 `head` 和数据集 `classes` 里。

### 2.6 SENet 在做什么

SE（Squeeze-and-Excitation）是一个**通道注意力**模块：

```
s = GlobalAvgPool(x)                 # (B, C, 1, 1)，squeeze
z = ReLU(FC1(s))                     # C -> C/r
w = Sigmoid(FC2(z))                  # C/r -> C，excitation
y = x * w                            # 逐通道缩放
```

- **插入位置**：Bottleneck 的最后一个 BN 之后、与 shortcut 相加之前。先 recalibrate 特征，再残差相加；
  放在相加之后会破坏恒等映射的干净路径。
- **reduction ratio** `r=16`；中间通道用 `make_divisible(C // r, 8)`，保证能被 8 整除。
  对 ResNet-50 的四个 stage：`C=256/512/1024/2048` → 中间通道 `16/32/64/128`。
- **SE 只加在 Bottleneck 上**：官方 `SEResNet` 只支持 depth 50/101/152；BasicBlock（18/34）没有官方 SE 版本。
- **FLOPs 几乎不变**：SE 只有全局池化 + 两个 1×1 卷积，计算量相比主干可以忽略；参数增加明显（见 2.7）。

### 2.7 SE-ResNet 家族（官方实现实测 + 官方模型库）

| depth | backbone 参数 | +1000 类 head | 比 ResNet 多 | backbone 键数 | FLOPs | ImageNet top-1 |
| :-: | :-: | :-: | :-: | :-: | :-: | :-: |
| 50 | 26.04 M | 28.09 M | +2.53 M（+10.8%） | 382 | 4.13 G | 77.74 |
| 101 | 47.28 M | 49.33 M | +4.78 M（+11.2%） | 756 | 7.86 G | 78.26 |
| 152 | 64.77 M | 66.82 M | +6.63 M（+11.4%） | 1130 | ≈11.6 G | 无官方权重 |

> 官方只发布了 SE-ResNet-50 / 101 的 ImageNet 权重；152 只能做结构对齐，或从零训练。
> 参数量增加这么多、FLOPs 几乎不变，是 SE 的典型特征：**用少量额外参数换通道重标定**。

### 3.3 注册名：不能叫 `ResNet` / `SEResNet`

mmpretrain 1.2.0 已经注册了官方 `'ResNet'` 和 `'SEResNet'`，同名注册会直接抛
`KeyError: 'ResNet' is already registered`。本项目用：

```python
@MODELS.register_module("MyResNet")     # resnet/backbones/resnet.py
class ResNet(BaseBackbone):
    ...

@MODELS.register_module("MySEResNet")   # resnet/backbones/senet.py
class SEResNet(ResNet):
    ...
```

好处：`type="ResNet"` 是官方实现、`type="MyResNet"` 是你的实现，同一个脚本里可以并存做对照；
`type="SEResNet"` 是官方 SE，`type="MySEResNet"` 是你的 SE，正好用来做结构对齐。

### 4.2 关键约束（写完逐条对照）

| # | 约束 | 不这么做会怎样 |
| :--- | :--- | :--- |
| 1 | 所有卷积 `bias=False` | `state_dict` 多出 bias 键；BN 前的 bias 是冗余参数 |
| 2 | `downsample` 条件 `stride != 1 or in_channels != out_channels` | layer1（64→256）漏掉 shortcut 投影，前向形状崩 |
| 3 | Bottleneck 的 stride 放在 **3×3** 上（`pytorch` style） | 特征图尺寸/键形状和官方不一致 |
| 4 | 通道：`_out_channels = base_channels * expansion`，每 stage 后 ×2 | 参数量对不上（差 0.01M 也算错） |
| 5 | `expansion`：BasicBlock=1，Bottleneck=4 | `mid_channels = out_channels // expansion` 错，1×1 通道全错 |
| 6 | stem：`7×7/2 conv 64` + BN + ReLU + `3×3/2 maxpool` | 224 输入到 layer1 不是 56×56 |
| 7 | `out_indices=(3,)` 返回 `tuple((B,C,7,7),)` | head 拿不到特征；`ImageClassifier` 会报维度错 |
| 8 | **backbone 不接 `num_classes`** | ResNet 的分类在 head，backbone 只输出特征图 |
| 9 | `train()` 必须 `return self` | 官方也没返回；`.eval()` 得到 `None`，下一行就 `AttributeError` |
| 10 | `_freeze_stages()` 在 `__init__` 里调用 | 和 VGG 不同：ResNet 构造完 `frozen_stages` 就生效 |

### 4.4 5 变体对齐：`tools/check_parity.py`

### 4.5 六个必须知道的坑

1. **`norm1` 是 property，不是普通属性**：`build_norm_layer` 返回 `(name, module)`，要把 module `add_module` 到
   `self.norm1_name`，再写 `@property def norm1(self): return getattr(self, self.norm1_name)`。
   少了 property，`forward` 里 `self.norm1` 直接 `AttributeError`（本机踩过）。
2. **`expansion` 放类属性**：`BasicBlock.expansion = 1`、`Bottleneck.expansion = 4`。`ResLayer` 在没传
   `expansion` 时靠它推断；写成实例属性也能跑，但 `ResNet` 里 `base_channels * expansion` 会拿不到。
3. **`downsample` 用 `nn.Sequential(conv, norm)`**，键名是 `downsample.0.weight` / `downsample.1.weight`；
   自己拼 `nn.ModuleDict` 或改顺序，`state_dict` 立刻对不上。
4. **`train()` 记得 `return self`**：官方 `ResNet.train()` 也没返回（源码里只有 `super().train(mode)` 和
   `_freeze_stages()`）。`.eval()` 返回 `None`，`a = OfficialResNet(...).eval()` 下一行就崩。
5. **`zero_init_residual` 会改 BN 的 γ**：`init_weights()` 里把每个 block 的最后一个 BN 权重置 0，
   让 block 初始是恒等映射；但 `init_cfg` 是 `Pretrained` 时要跳过，否则会把官方权重覆盖成 0。
6. **`frozen_stages` 在构造时就生效**：`__init__` 末尾调 `_freeze_stages()`；VGG 是写在 `train()` 里、
   构造完不生效。两个项目行为不同，别混。

## Phase 5：集成 SENet（额外要求）

> mmpretrain 1.2.0 里**已经有**官方 `SEResNet`（`type="SEResNet"`）。直接调它能跑，但那是「调包」，
> 不是「集成」；本 Phase 要求你自己写 `SELayer` / `SEBottleneck`，再拿官方 `SEResNet` 当**结构对齐的基准**。
> 这和 VGG 那套「官方 `VGG` 是参照物，自己写 `VGGNet`」是同一个思路。

### 5.1 SE 的插入位置

```
Bottleneck:
  x ── conv1 1x1 ── BN ── ReLU ── conv2 3x3 ── BN ── ReLU ── conv3 1x1 ── BN ── SE ──┐
  │                                                                                    + ── ReLU ── y
  └──────────────────────── shortcut（1x1 conv + BN 或恒等）──────────────────────────┘
```

- SE 在 **最后一个 BN 之后、加法之前**。
- `shortcut` 不经过 SE；SE 只重标定残差分支。
- SE 的输入输出通道相同（`C → C`），所以可以直接逐通道相乘，不改变张量形状。

### 5.2 `SELayer`

```python
class SELayer(BaseModule):
    def __init__(self, channels, ratio=16, divisor=8, conv_cfg=None,
                 act_cfg=(dict(type="ReLU"), dict(type="Sigmoid")),
                 init_cfg=None):
        super().__init__(init_cfg)
        if isinstance(act_cfg, dict):
            act_cfg = (act_cfg, act_cfg)
        self.global_avgpool = torch.nn.AdaptiveAvgPool2d(1)
        squeeze_channels = make_divisible(channels // ratio, divisor)
        self.conv1 = ConvModule(
            channels, squeeze_channels, 1, bias="auto",
            conv_cfg=conv_cfg, act_cfg=act_cfg[0])
        self.conv2 = ConvModule(
            squeeze_channels, channels, 1, bias="auto",
            conv_cfg=conv_cfg, act_cfg=act_cfg[1])

    def forward(self, x):
        return x * self.conv2(self.conv1(self.global_avgpool(x)))
```

`make_divisible` 从 `mmpretrain.models.utils` 导入。`ConvModule` 的 `bias="auto"` 在没有 norm 时会自动加 bias，
和官方 `SELayer` 一致；这也是 `state_dict` 里 SE 的 1×1 卷积有 `.bias` 的原因。

### 5.3 `SEBottleneck`

```python
class SEBottleneck(Bottleneck):
    def __init__(self, in_channels, out_channels, se_ratio=16, **kwargs):
        super().__init__(in_channels, out_channels, **kwargs)
        self.se_layer = SELayer(out_channels, ratio=se_ratio)

    def forward(self, x):
        def _inner_forward(x):
            identity = x
            out = self.relu(self.norm1(self.conv1(x)))
            out = self.relu(self.norm2(self.conv2(out)))
            out = self.norm3(self.conv3(out))
            out = self.se_layer(out)
            if self.downsample is not None:
                identity = self.downsample(x)
            out += identity
            return out

        if self.with_cp and x.requires_grad:
            out = cp.checkpoint(_inner_forward, x)
        else:
            out = _inner_forward(x)
        return self.relu(out)
```

**命名必须是 `se_layer`**，不是 `se`。官方 `state_dict` 的键是
`layer1.0.se_layer.conv1.conv.weight`；写成 `self.se = ...`，键就变成 `layer1.0.se.conv1.conv.weight`，
结构对齐直接失败。这是 SE 集成最常见的“明明代码一样但 `diff` 不为 0”的原因。

### 5.4 `SEResNet`

```python
@MODELS.register_module("MySEResNet")
class SEResNet(ResNet):
    arch_settings = {
        50: (SEBottleneck, (3, 4, 6, 3)),
        101: (SEBottleneck, (3, 4, 23, 3)),
        152: (SEBottleneck, (3, 8, 36, 3)),
    }

    def __init__(self, depth, se_ratio=16, **kwargs):
        if depth not in self.arch_settings:
            raise KeyError(f"invalid depth {depth} for SEResNet")
        self.se_ratio = se_ratio
        super().__init__(depth, **kwargs)

    def make_res_layer(self, **kwargs):
        return ResLayer(se_ratio=self.se_ratio, **kwargs)
```

`ResLayer` 通过 `**kwargs` 把 `se_ratio` 传给每个 block；`SEBottleneck` 的签名里有 `se_ratio`，正好接住。
`ResNet` 的 `forward` / `_freeze_stages` / `init_weights` 全部复用，不需要改。

### 5.6 SE 参数量怎么算

每个 SE 块（输入输出都是 `C`，`r=16`）：

```
FC1: C × (C/r) + C/r
FC2: (C/r) × C + C
合计: 2C²/r + C + C/r
```

ResNet-50 的 16 个 Bottleneck：

| stage | C | block 数 | 每块 SE 参数 | 小计 |
| :--- | :-: | :-: | :-: | :-: |
| layer1 | 256 | 3 | 8,464 | 25,392 |
| layer2 | 512 | 4 | 33,312 | 133,248 |
| layer3 | 1024 | 6 | 132,160 | 792,960 |
| layer4 | 2048 | 3 | 526,464 | 1,579,392 |
| **合计** | | 16 | | **2,530,992（≈2.53M）** |

和实测 `26.04 - 23.51 = 2.53M` 完全对得上。101/152 的 block 数更多、stage4 占比更高，所以增加 4.78M / 6.63M。

### 5.7 SE 的 `state_dict` 键长什么样

```
layer1.0.se_layer.conv1.conv.weight   (16, 256, 1, 1)
layer1.0.se_layer.conv1.conv.bias     (16,)
layer1.0.se_layer.conv2.conv.weight   (256, 16, 1, 1)
layer1.0.se_layer.conv2.conv.bias     (256,)
```

- ResNet-50 有 16 个 block → **64 个 SE 参数键**；101 有 33 个 → 132；152 有 50 个 → 200。
- 这 64 个键就是「普通 ResNet-50 权重 → SE-ResNet-50」时缺失的全部键（6.3 会验证）。
- 如果你把 `SELayer` 写成 `self.fc1 = nn.Linear(...)`，键名会变成 `se_layer.fc1.weight`，和官方对不上；
  用 `ConvModule` 是为了同时对齐「1×1 卷积 + 激活」的结构和键名。

### 6.1 三条路，别用错

| 方式 | 在哪生效 | 适用场景 | 注意 |
| :--- | :--- | :--- | :--- |
| `get_model("resnet50_8xb32_in1k", pretrained=True)` | 推理 / 结构验证 | 确认权重能跑通、做官方基线 | 自动下载 ~98MB |

### 6.4 1000 类 → 2 类：尺寸不匹配是**预期行为**

猫狗只有 2 类，`head.fc` 必须重建为 `Linear(2048, 2)`。用 `load_from` 加载 1000 类权重时，
mmengine 会打一条警告然后**跳过这两个键**，backbone 的 318 个键照常加载（本机实测日志）：

```
The model and loaded state dict do not match exactly

size mismatch for head.fc.weight: copying a param with shape torch.Size([1000, 2048]) from checkpoint, the shape in current model is torch.Size([2, 2048]).
size mismatch for head.fc.bias: copying a param with shape torch.Size([1000]) from checkpoint, the shape in current model is torch.Size([2]).
```

- 看到这两行 **不要慌，也不要改 `strict=True`**——这正是你要的效果：
  卷积 + BN 全部复用，最后一层随机初始化等训练。
- 和 VGG 的区别：VGG 报的是 `backbone.classifier.6.*`，ResNet 报的是 `head.fc.*`。
  如果你在 ResNet 日志里看到 `classifier.6`，说明模型建错成 VGG 了。

### 6.5 必装补丁：torch ≥2.6 读 mmengine checkpoint 会报错

`torch.load` 从 2.6 起默认 `weights_only=True`，而 mmengine 0.10.7 存盘时带了 `HistoryBuffer`：

```
_pickle.UnpicklingError: Weights only load failed ...
WeightsUnpickler error: Unsupported global: GLOBAL mmengine.logging.history_buffer.HistoryBuffer
```

**影响**：断点续训（`--resume`）、`load_from` 指向自己训出来的 ckpt、`Runner.test()` 全部失败（本机已实测）。
`load_from` 官方权重没问题，是因为官方 ckpt 里没有这些对象。

新建 `tools/compat.py`（三个入口脚本顶部 `import compat`）：

```python
"""torch>=2.6 的 torch.load(weights_only=True) 与 mmengine 0.10.7 checkpoint 不兼容的补丁。"""
import torch

_original_load = torch.load


def _patched_load(*args, **kwargs):
    kwargs.setdefault("weights_only", False)   # 只对可信的本地/官方 ckpt
    return _original_load(*args, **kwargs)


torch.load = _patched_load
```

> 为什么不用 `torch.serialization.add_safe_globals`：实测只加 `HistoryBuffer` 仍然失败（checkpoint 里还有别的对象），
> 逐个加太脆。`weights_only=False` 是官方文档给出的方案，只要**只加载自己训的 / 官方发布的 ckpt** 就安全。

| 报错 | 原因 | 解决 |

| `KeyError: 'ResNet' is already registered` | 用了官方的注册名 | `@MODELS.register_module("MyResNet")` |

### B.1 `resnet/backbones/resnet.py`

```python
import torch
import torch.utils.checkpoint as cp
from mmcv.cnn import (build_activation_layer, build_conv_layer,
                      build_norm_layer)
from mmengine.model import BaseModule
from mmengine.model.weight_init import constant_init
from mmengine.utils.dl_utils.parrots_wrapper import _BatchNorm

from mmpretrain.models.backbones.base_backbone import BaseBackbone
from mmpretrain.registry import MODELS


class BasicBlock(BaseModule):
    """ResNet basic block: 2 x 3x3 conv + BN, plus identity shortcut."""

    expansion = 1

    def __init__(self, in_channels, out_channels, expansion=1, stride=1,
                 dilation=1, downsample=None, style="pytorch", with_cp=False,
                 conv_cfg=None, norm_cfg=dict(type="BN"),
                 act_cfg=dict(type="ReLU", inplace=True), init_cfg=None):
        super().__init__(init_cfg=init_cfg)
        self.in_channels = in_channels
        self.out_channels = out_channels
        self.expansion = expansion
        self.mid_channels = out_channels // expansion
        self.stride = stride
        self.dilation = dilation
        self.with_cp = with_cp

        self.norm1_name, norm1 = build_norm_layer(
            norm_cfg, self.mid_channels, postfix=1)
        self.norm2_name, norm2 = build_norm_layer(
            norm_cfg, out_channels, postfix=2)
        self.conv1 = build_conv_layer(
            conv_cfg, in_channels, self.mid_channels, 3, stride=stride,
            padding=dilation, dilation=dilation, bias=False)
        self.add_module(self.norm1_name, norm1)
        self.conv2 = build_conv_layer(
            conv_cfg, self.mid_channels, out_channels, 3, padding=1,
            bias=False)
        self.add_module(self.norm2_name, norm2)
        self.relu = build_activation_layer(act_cfg)
        self.downsample = downsample

    @property
    def norm1(self):
        return getattr(self, self.norm1_name)

    @property
    def norm2(self):
        return getattr(self, self.norm2_name)

    def forward(self, x):
        def _inner_forward(x):
            identity = x
            out = self.relu(self.norm1(self.conv1(x)))
            out = self.norm2(self.conv2(out))
            if self.downsample is not None:
                identity = self.downsample(x)
            out += identity
            return out

        if self.with_cp and x.requires_grad:
            out = cp.checkpoint(_inner_forward, x)
        else:
            out = _inner_forward(x)
        return self.relu(out)


class Bottleneck(BaseModule):
    """ResNet bottleneck: 1x1 -> 3x3 (stride) -> 1x1, plus shortcut."""

    expansion = 4

    def __init__(self, in_channels, out_channels, expansion=4, stride=1,
                 dilation=1, downsample=None, style="pytorch", with_cp=False,
                 conv_cfg=None, norm_cfg=dict(type="BN"),
                 act_cfg=dict(type="ReLU", inplace=True), init_cfg=None):
        super().__init__(init_cfg=init_cfg)
        assert style in ["pytorch", "caffe"]
        self.in_channels = in_channels
        self.out_channels = out_channels
        self.expansion = expansion
        self.mid_channels = out_channels // expansion
        self.stride = stride
        self.dilation = dilation
        self.with_cp = with_cp
        if style == "pytorch":
            self.conv1_stride, self.conv2_stride = 1, stride
        else:
            self.conv1_stride, self.conv2_stride = stride, 1

        self.norm1_name, norm1 = build_norm_layer(
            norm_cfg, self.mid_channels, postfix=1)
        self.norm2_name, norm2 = build_norm_layer(
            norm_cfg, self.mid_channels, postfix=2)
        self.norm3_name, norm3 = build_norm_layer(
            norm_cfg, out_channels, postfix=3)
        self.conv1 = build_conv_layer(
            conv_cfg, in_channels, self.mid_channels, 1,
            stride=self.conv1_stride, bias=False)
        self.add_module(self.norm1_name, norm1)
        self.conv2 = build_conv_layer(
            conv_cfg, self.mid_channels, self.mid_channels, 3,
            stride=self.conv2_stride, padding=dilation, dilation=dilation,
            bias=False)
        self.add_module(self.norm2_name, norm2)
        self.conv3 = build_conv_layer(
            conv_cfg, self.mid_channels, out_channels, 1, bias=False)
        self.add_module(self.norm3_name, norm3)
        self.relu = build_activation_layer(act_cfg)
        self.downsample = downsample

    @property
    def norm1(self):
        return getattr(self, self.norm1_name)

    @property
    def norm2(self):
        return getattr(self, self.norm2_name)

    @property
    def norm3(self):
        return getattr(self, self.norm3_name)

    def forward(self, x):
        def _inner_forward(x):
            identity = x
            out = self.relu(self.norm1(self.conv1(x)))
            out = self.relu(self.norm2(self.conv2(out)))
            out = self.norm3(self.conv3(out))
            if self.downsample is not None:
                identity = self.downsample(x)
            out += identity
            return out

        if self.with_cp and x.requires_grad:
            out = cp.checkpoint(_inner_forward, x)
        else:
            out = _inner_forward(x)
        return self.relu(out)


class ResLayer(torch.nn.Sequential):
    """One stage: the first block may downsample, the rest keep shape."""

    def __init__(self, block, num_blocks, in_channels, out_channels,
                 expansion=None, stride=1, avg_down=False, conv_cfg=None,
                 norm_cfg=dict(type="BN"), **kwargs):
        self.block = block
        self.expansion = expansion if expansion is not None else block.expansion
        downsample = None
        if stride != 1 or in_channels != out_channels:
            downsample = []
            conv_stride = stride
            if avg_down and stride != 1:
                conv_stride = 1
                downsample.append(
                    torch.nn.AvgPool2d(
                        kernel_size=stride, stride=stride, ceil_mode=True,
                        count_include_pad=False))
            downsample.extend([
                build_conv_layer(
                    conv_cfg, in_channels, out_channels, kernel_size=1,
                    stride=conv_stride, bias=False),
                build_norm_layer(norm_cfg, out_channels)[1],
            ])
            downsample = torch.nn.Sequential(*downsample)

        layers = []
        layers.append(
            block(
                in_channels=in_channels, out_channels=out_channels,
                expansion=self.expansion, stride=stride,
                downsample=downsample, conv_cfg=conv_cfg,
                norm_cfg=norm_cfg, **kwargs))
        in_channels = out_channels
        for _ in range(1, num_blocks):
            layers.append(
                block(
                    in_channels=in_channels, out_channels=out_channels,
                    expansion=self.expansion, stride=1,
                    conv_cfg=conv_cfg, norm_cfg=norm_cfg, **kwargs))
        super().__init__(*layers)


@MODELS.register_module("MyResNet")
class ResNet(BaseBackbone):
    """Hand-written ResNet, registered as ``MyResNet``."""

    arch_settings = {
        18: (BasicBlock, (2, 2, 2, 2)),
        34: (BasicBlock, (3, 4, 6, 3)),
        50: (Bottleneck, (3, 4, 6, 3)),
        101: (Bottleneck, (3, 4, 23, 3)),
        152: (Bottleneck, (3, 8, 36, 3)),
    }

    def __init__(self, depth, in_channels=3, stem_channels=64,
                 base_channels=64, expansion=None, num_stages=4,
                 strides=(1, 2, 2, 2), dilations=(1, 1, 1, 1),
                 out_indices=(3,), style="pytorch", avg_down=False,
                 frozen_stages=-1, conv_cfg=None,
                 norm_cfg=dict(type="BN", requires_grad=True),
                 norm_eval=False, with_cp=False, zero_init_residual=True,
                 init_cfg=[dict(type="Kaiming", layer=["Conv2d"]),
                           dict(type="Constant", val=1,
                                layer=["_BatchNorm", "GroupNorm"])]):
        super().__init__(init_cfg)
        if depth not in self.arch_settings:
            raise KeyError(f"invalid depth {depth} for resnet")
        self.depth = depth
        self.stem_channels = stem_channels
        self.base_channels = base_channels
        self.num_stages = num_stages
        assert 1 <= num_stages <= 4
        self.strides = strides
        self.dilations = dilations
        assert len(strides) == len(dilations) == num_stages
        self.out_indices = out_indices
        assert max(out_indices) < num_stages
        self.style = style
        self.frozen_stages = frozen_stages
        self.conv_cfg = conv_cfg
        self.norm_cfg = norm_cfg
        self.with_cp = with_cp
        self.norm_eval = norm_eval
        self.zero_init_residual = zero_init_residual
        self.block, stage_blocks = self.arch_settings[depth]
        self.stage_blocks = stage_blocks[:num_stages]
        self.expansion = (expansion if expansion is not None
                          else self.block.expansion)

        self._make_stem_layer(in_channels, stem_channels)

        self.res_layers = []
        _in_channels = stem_channels
        _out_channels = base_channels * self.expansion
        for i, num_blocks in enumerate(self.stage_blocks):
            res_layer = self.make_res_layer(
                block=self.block, num_blocks=num_blocks,
                in_channels=_in_channels, out_channels=_out_channels,
                expansion=self.expansion, stride=strides[i],
                dilation=dilations[i], style=self.style, avg_down=avg_down,
                with_cp=with_cp, conv_cfg=conv_cfg, norm_cfg=norm_cfg)
            _in_channels = _out_channels
            _out_channels *= 2
            layer_name = f"layer{i + 1}"
            self.add_module(layer_name, res_layer)
            self.res_layers.append(layer_name)

        self._freeze_stages()
        self.feat_dim = res_layer[-1].out_channels

    def make_res_layer(self, **kwargs):
        return ResLayer(**kwargs)

    @property
    def norm1(self):
        return getattr(self, self.norm1_name)

    def _make_stem_layer(self, in_channels, stem_channels):
        self.conv1 = build_conv_layer(
            self.conv_cfg, in_channels, stem_channels, kernel_size=7,
            stride=2, padding=3, bias=False)
        self.norm1_name, norm1 = build_norm_layer(
            self.norm_cfg, stem_channels, postfix=1)
        self.add_module(self.norm1_name, norm1)
        self.relu = torch.nn.ReLU(inplace=True)
        self.maxpool = torch.nn.MaxPool2d(kernel_size=3, stride=2, padding=1)

    def _freeze_stages(self):
        if self.frozen_stages >= 0:
            self.norm1.eval()
            for m in [self.conv1, self.norm1]:
                for param in m.parameters():
                    param.requires_grad = False
        for i in range(1, self.frozen_stages + 1):
            m = getattr(self, f"layer{i}")
            m.eval()
            for param in m.parameters():
                param.requires_grad = False

    def init_weights(self):
        super().init_weights()
        if (isinstance(self.init_cfg, dict)
                and self.init_cfg["type"] == "Pretrained"):
            return
        if self.zero_init_residual:
            for m in self.modules():
                if isinstance(m, Bottleneck):
                    constant_init(m.norm3, 0)
                elif isinstance(m, BasicBlock):
                    constant_init(m.norm2, 0)

    def forward(self, x):
        x = self.relu(self.norm1(self.conv1(x)))
        x = self.maxpool(x)
        outs = []
        for i, layer_name in enumerate(self.res_layers):
            x = getattr(self, layer_name)(x)
            if i in self.out_indices:
                outs.append(x)
        return tuple(outs)

    def train(self, mode=True):
        super().train(mode)
        self._freeze_stages()
        if mode and self.norm_eval:
            for m in self.modules():
                if isinstance(m, _BatchNorm):
                    m.eval()
        return self
```

### B.2 `resnet/backbones/senet.py`

```python
import torch
import torch.utils.checkpoint as cp
from mmcv.cnn import ConvModule
from mmengine.model import BaseModule

from mmpretrain.models.utils import make_divisible
from mmpretrain.registry import MODELS

from .resnet import Bottleneck, ResLayer, ResNet


class SELayer(BaseModule):
    """Squeeze-and-Excitation: global avg pool -> FC -> ReLU -> FC -> Sigmoid."""

    def __init__(self, channels, ratio=16, divisor=8, conv_cfg=None,
                 act_cfg=(dict(type="ReLU"), dict(type="Sigmoid")),
                 init_cfg=None):
        super().__init__(init_cfg)
        if isinstance(act_cfg, dict):
            act_cfg = (act_cfg, act_cfg)
        self.global_avgpool = torch.nn.AdaptiveAvgPool2d(1)
        squeeze_channels = make_divisible(channels // ratio, divisor)
        self.conv1 = ConvModule(
            channels, squeeze_channels, 1, bias="auto",
            conv_cfg=conv_cfg, act_cfg=act_cfg[0])
        self.conv2 = ConvModule(
            squeeze_channels, channels, 1, bias="auto",
            conv_cfg=conv_cfg, act_cfg=act_cfg[1])

    def forward(self, x):
        return x * self.conv2(self.conv1(self.global_avgpool(x)))


class SEBottleneck(Bottleneck):
    """Bottleneck with an SE branch after the last BN, before the add."""

    def __init__(self, in_channels, out_channels, se_ratio=16, **kwargs):
        super().__init__(in_channels, out_channels, **kwargs)
        self.se_layer = SELayer(out_channels, ratio=se_ratio)

    def forward(self, x):
        def _inner_forward(x):
            identity = x
            out = self.relu(self.norm1(self.conv1(x)))
            out = self.relu(self.norm2(self.conv2(out)))
            out = self.norm3(self.conv3(out))
            out = self.se_layer(out)
            if self.downsample is not None:
                identity = self.downsample(x)
            out += identity
            return out

        if self.with_cp and x.requires_grad:
            out = cp.checkpoint(_inner_forward, x)
        else:
            out = _inner_forward(x)
        return self.relu(out)


@MODELS.register_module("MySEResNet")
class SEResNet(ResNet):
    """SE-ResNet, registered as ``MySEResNet`` (depth 50/101/152)."""

    arch_settings = {
        50: (SEBottleneck, (3, 4, 6, 3)),
        101: (SEBottleneck, (3, 4, 23, 3)),
        152: (SEBottleneck, (3, 8, 36, 3)),
    }

    def __init__(self, depth, se_ratio=16, **kwargs):
        if depth not in self.arch_settings:
            raise KeyError(f"invalid depth {depth} for SEResNet")
        self.se_ratio = se_ratio
        super().__init__(depth, **kwargs)

    def make_res_layer(self, **kwargs):
        return ResLayer(se_ratio=self.se_ratio, **kwargs)
```
