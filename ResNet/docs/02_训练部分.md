### 8.3 关键一致性（ResNet-50 版）

| 位置 | 值 | 不一致的后果 |
| :--- | :--- | :--- |
| `model.head.num_classes` | 2 | 输出 1000 维，loss 形状不匹配 |
| 数据集 `classes` / 目录 | `("cat","dog")` | 类别数与 label 越界 |
| `model.head.in_channels` | **2048**（ResNet-50） | `mat1 and mat2 shapes cannot be multiplied` |
| `data_preprocessor.num_classes` | 2 | 只在 `to_onehot=True` 或 batch augment 时参与 one-hot；建议保持一致，避免以后加 mixup 时踩坑 |

> **和 VGG 最大的不同**：ResNet 的 backbone **没有** `num_classes` 参数，分类数只在 `head` 里。
> 不要写 `backbone=dict(type="MyResNet", depth=50, num_classes=2)`，会直接
> `TypeError: __init__() got an unexpected keyword argument 'num_classes'`。
>
> 另外，mmpretrain 1.2.0 的 `ClsDataPreprocessor` 默认 `to_onehot=False`，只写 `num_classes=2`
> **不会**自动把 label 转 one-hot；默认用 int label 走 `CrossEntropyLoss` 完全正常。
> 只有开了 mixup/cutmix 才需要 `to_onehot=True`，那时 `num_classes` 必须和 head 一致。

### 8.4 训练策略

**默认（推荐先跑这个）**：全量微调 **10 epoch**，`lr=0.01` + cosine，AMP，bs32。
本机预计 **1–2 分钟/epoch**（22.5k 张，ResNet-50 比 VGG16 轻很多），10 epoch + 10 次验证大约 **20–30 分钟**。
SE-ResNet-50 多约 10–20% 计算，预计 **25–35 分钟**。

**如果 loss 不稳定 / 第 1 epoch 掉到 90% 以下**：把 `lr` 降到 `1e-3` 再跑。ResNet 有 BN，通常比无 BN 的 VGG
耐得住大 lr，但微调预训练模型时 0.01 已经不算小。

**两段式（精度更稳，或时间紧时先看趋势）**：

1. 第一阶段：`backbone` 加 `frozen_stages=4`（冻结 stem + 4 个 stage，只训 `head.fc`），`lr=1e-3`，1–2 epoch；
2. 第二阶段：去掉 `frozen_stages`，`load_from` 指向第一阶段的 `epoch_2.pth`，`lr=1e-4`，再训 8–10 epoch。

> `frozen_stages` 是构造参数，训练中途改不了；两段式就是**两次 run**，不是同一 run 里切。
> 只训 head 的线性探针在猫狗上通常也能到 **96%–97%**，可以作为「预训练权重确实加载成功」的强证据。

**预期精度**：ImageNet 预训练 ResNet-50 + 25k 猫狗，10 epoch 全量微调一般在 **97%–99.5%**；
SE-ResNet-50 与 ResNet-50 通常只差 **±0.3 个点**。
**> 95% 是很有余量的目标**，不用刻意调。

### 8.7 常见失败

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| `loss: nan` | lr 太大（0.01 对某些初始化偏大），或没加载预训练 | 先降到 `1e-3`；确认日志里有 `Load checkpoint from ...` |
| 第 1 epoch 只有 ~80% | 权重没加载（URL 写错 / 被 `init_cfg` 覆盖 / 配置里漏了 `load_from`） | 看启动日志前 20 行有没有加载成功的记录 |
| `AssertionError: The number of subfolders (2) doesn't match ... (1000)` | `classes` 没传 | `dataset=dict(classes=classes)` |
| `mat1 and mat2 shapes cannot be multiplied` | `head.in_channels` 写错（ResNet-50 是 2048） | 改 `head.in_channels=2048` |
| `TypeError: __init__() got an unexpected keyword argument 'num_classes'` | 给 ResNet backbone 传了 `num_classes` | 删掉；类别数放 `head.num_classes` |
| `KeyError: 'MyResNet' is not in the registry` | 注册没执行 / import 失败被吞 | 确认 `import resnet` + `pip install -e .` |
| `KeyError: 'MySEResNet' is not in the registry` | `senet.py` 没被 import | `resnet/backbones/__init__.py` 导出 + 入口 `import resnet` |
| checkpoint 加载报 `UnpicklingError` | 6.5 的补丁没加 | `import compat` |
| `DataLoader worker ... exited unexpectedly`（Windows） | spawn + 中文路径 + 大内存 | 冒烟 `num_workers=0`；稳定后 4–8 |
| `CUDA out of memory` | bs 太大 / 没开 AMP | bs 降到 16，开 `AmpOptimWrapper`，或 `with_cp=True` |

### 9.3 如果没到 95%

按顺序试，不要一次改三个：

1. **确认权重加载**：日志前 20 行必须有 `Load checkpoint from ...resnet50...`；没有就是配置写错/被覆盖。
2. **降 lr**：`0.01 → 0.001`，再跑 10 epoch。ResNet 微调 lr 太大时 loss 会抖。
3. **加 epoch**：10 → 15，cosine 的 `T_max` 一起改。
4. **冻结 warmup**：`frozen_stages=4`、lr=1e-3 跑 2 epoch，再解冻、lr=1e-4 跑 8 epoch（8.4 的两段式）。
5. **查数据**：类别目录、坏图、训练/验证是否串了；`classes` 顺序是否和目录一致。
6. **确认没把 `head.fc` 当预训练权重**：`head.fc` 是随机初始化的，前 2–3 个 iter loss 高是正常的。

### 12.5 SE 门控可视化：`tools/visualize_se.py`

SE 的 gate 是 `SELayer.conv2` 的输出（Sigmoid 后，形状 `(B, C, 1, 1)`），不是 `SELayer` 的最终输出
（最终输出是 `x * gate`，已经乘回特征图）。用 forward hook 抓 `conv2`：

```python
import argparse

import torch
from mmengine.config import Config
from mmengine.dataset import Compose
from mmpretrain import get_model
from mmpretrain.registry import TRANSFORMS

import resnet  # noqa: F401


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("config")
    parser.add_argument("checkpoint")
    parser.add_argument("image")
    args = parser.parse_args()

    cfg = Config.fromfile(args.config)
    model = get_model(Config(dict(model=cfg.model,
                                  data_preprocessor=cfg.data_preprocessor)))
    ckpt = torch.load(args.checkpoint, map_location="cpu", weights_only=False)
    model.load_state_dict(ckpt["state_dict"], strict=False)
    model.eval()

    gates = {}
    hooks = []
    for name, module in model.backbone.named_modules():
        if name.endswith("se_layer.conv2"):
            def hook(m, i, o, name=name):
                gates[name] = o.detach().flatten(1)
            hooks.append(module.register_forward_hook(hook))

    pipeline = Compose([TRANSFORMS.build(t) for t in cfg.test_pipeline])
    sample = pipeline(dict(img_path=args.image))
    batch = dict(inputs=sample["inputs"].unsqueeze(0),
                 data_samples=[sample["data_samples"]])

    with torch.no_grad():
        pred = model.test_step(batch)[0]

    print("预测:", cfg.classes[pred.pred_label.item()],
          "| 概率: %.4f" % pred.pred_score.max().item())
    for stage in ("layer1", "layer2", "layer3", "layer4"):
        vals = torch.cat([v for k, v in gates.items()
                          if k.startswith(stage + ".")])
        print(f"{stage}: mean={vals.mean():.4f} std={vals.std():.4f} "
              f"min={vals.min():.4f} max={vals.max():.4f}")

    for h in hooks:
        h.remove()


if __name__ == "__main__":
    main()
```

```powershell
python ResNet\tools\visualize_se.py ^
  ResNet\config\seresnet50_cats_dogs.py ^
  work_dirs\seresnet50_cats_dogs\best_accuracy_top1_epoch_?.pth ^
  validation_photos\dog1.png
```

用**官方 SE-ResNet-50 权重**跑 `validation_photos/dog1.png` 的示例输出（仅演示脚本能跑，数值随图/权重变化）：

```

layer1: mean=0.4500 std=0.1024 min=0.0275 max=0.7365
layer2: mean=0.4860 std=0.0780 min=0.0306 max=0.7026
layer3: mean=0.4845 std=0.0885 min=0.0142 max=0.7665
layer4: mean=0.9395 std=0.0434 min=0.2544 max=0.9974
```

> 解读别过度：gate 均值接近 0.5 表示「一半通道被保留」，接近 1 表示「几乎不抑制」。
> 层越深 gate 均值越高（示例里 layer4 ≈0.94）是常见现象，但**不能**直接当成「SE 学到了语义」的证据；
> 它只说明门控不是恒定的，SE 分支确实在工作。

| 第 1 epoch 精度只有 ~80% | `load_from` 没生效 / URL 写错 / 被 `init_cfg` 覆盖 | 看日志前 20 行；确认 `Load checkpoint from ...` |
| 第 1 epoch 就 >99%，之后下降 | 数据简单 + 过拟合 | 正常；用 `save_best` 的 ckpt，不要用最后一个 |
| `CUDA out of memory` | bs 太大 / 没开 AMP | bs 16 + `AmpOptimWrapper`；或 `with_cp=True` |
