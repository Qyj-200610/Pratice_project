## Phase 7：迁移学习训练（目标 3）

### 7.1 `config/vgg16net_cats_dogs.py`（已实测跑通 1 epoch）

```python
# 真实猫狗训练配置（自包含，不继承 _base_，避免 1000 类设置漏覆盖）
# 数据：Pratice_project/data/cats_dogs（tools/prepare_cats_dogs.py 生成）
# 启动：在 Pratice_project/ 下执行
#   python VGGNet/tools/train.py VGGNet/config/vgg16net_cats_dogs.py
data_root = "data/cats_dogs"      # 相对当前工作目录
classes = ("cat", "dog")

model = dict(
    type="ImageClassifier",
    backbone=dict(type="VGGNet", depth=16, num_classes=2),
    neck=None,
    head=dict(
        type="ClsHead",
        loss=dict(type="CrossEntropyLoss", loss_weight=1.0),
        topk=(1,),
    ),
)

data_preprocessor = dict(
    num_classes=2,
    mean=[123.675, 116.28, 103.53],
    std=[58.395, 57.12, 57.375],
    to_rgb=True,
)

train_pipeline = [
    dict(type="LoadImageFromFile"),
    dict(type="RandomResizedCrop", scale=224, backend="pillow"),
    dict(type="RandomFlip", prob=0.5, direction="horizontal"),
    dict(type="PackInputs"),
]
test_pipeline = [
    dict(type="LoadImageFromFile"),
    dict(type="ResizeEdge", scale=256, edge="short", backend="pillow"),
    dict(type="CenterCrop", crop_size=224),
    dict(type="PackInputs"),
]

train_dataloader = dict(
    batch_size=32,
    num_workers=4,
    dataset=dict(
        type="ImageNet",
        data_root=data_root,
        split="train",
        classes=classes,
        pipeline=train_pipeline,
    ),
    sampler=dict(type="DefaultSampler", shuffle=True),
)
val_dataloader = dict(
    batch_size=32,
    num_workers=4,
    dataset=dict(
        type="ImageNet",
        data_root=data_root,
        split="val",
        classes=classes,
        pipeline=test_pipeline,
    ),
    sampler=dict(type="DefaultSampler", shuffle=False),
)
val_evaluator = dict(type="Accuracy", topk=(1,))
test_dataloader = val_dataloader
test_evaluator = val_evaluator

# 本机实测：bs32/AMP 峰值约 3GB、~118 img/s
optim_wrapper = dict(
    type="AmpOptimWrapper",
    optimizer=dict(type="SGD", lr=1e-4, momentum=0.9, weight_decay=1e-4),
)
param_scheduler = [
    dict(type="CosineAnnealingLR", T_max=8, eta_min=1e-6, by_epoch=True,
         begin=0, end=8),
]

train_cfg = dict(by_epoch=True, max_epochs=8, val_interval=1)
val_cfg = dict()
test_cfg = dict()

# 单卡 bs32 为基准；2 卡 DDP 时总 batch 64，lr 自动 ×2
auto_scale_lr = dict(base_batch_size=32, enable=True)

default_hooks = dict(
    checkpoint=dict(type="CheckpointHook", interval=1,
                    save_best="accuracy/top1", max_keep_ckpts=2),
)

# TensorBoard：装了 tensorboard 才加 backend，没装时训练照常跑。
# 注意：config 里不能写 `import tensorboard` / `from x import y` 再调用——
# mmengine 会把它们变成 LazyObject（调用报 RuntimeError），
# 且模块名会作为全局变量存进 Config，Runner 深拷贝时报 "cannot pickle 'module' object"。
vis_backends = [dict(type="LocalVisBackend")]
try:

    vis_backends.append(dict(type="TensorboardVisBackend"))
except ImportError:
    pass
visualizer = dict(type="UniversalVisualizer", vis_backends=vis_backends)

# Windows 本机不跑 DDP；恒源云 2 卡用 nccl
env_cfg = dict(
    cudnn_benchmark=False,
    mp_cfg=dict(mp_start_method="spawn", opencv_num_threads=0),
    dist_cfg=dict(backend="nccl"),
)

# 官方 1000 类权重：卷积 + 前两层 FC 复用，classifier.6 重建（会打 2 条 size mismatch 警告，正常）
load_from = ("https://download.openmmlab.com/mmclassification/v0/vgg/"
             "vgg16_batch256_imagenet_20210208-db26f1a5.pth")

default_scope = "mmpretrain"
log_level = "INFO"
work_dir = "work_dirs/vgg16net_cats_dogs"
```

### 7.2 三处 `num_classes` 必须一致

| 位置 | 值 | 不一致的后果 |
| :--- | :--- | :--- |
| `model.backbone.num_classes` | 2 | 输出 1000 维，loss 形状不匹配 |
| `data_preprocessor.num_classes` | 2 | 设了它就会自动开 one-hot，长度对不上直接报错 |
| `classes` / 数据目录 | `("cat","dog")` | 类别数与 label 越界 |

- `head.topk=(1,)`：2 分类算 top5 没意义，evaluator 的 `topk` 也要同步改成 `(1,)`。

### 7.3 训练策略

**默认（推荐先跑这个）**：全量微调 8 epoch，`lr=1e-4` + cosine，AMP，bs32。
本机预计 **3–5 分钟/epoch**（22.5k 张；实测 118 img/s 是纯计算上限，算上取数按一半估），
8 epoch + 8 次验证大约 **40–60 分钟**。

**可选两段式**（精度更稳，或时间紧时先看趋势）：

1. 第一阶段：`backbone` 加 `frozen_stages=5`（冻结全部卷积，只训 3 层 FC），`lr=1e-3`，1–2 epoch；
2. 第二阶段：去掉 `frozen_stages`，`load_from` 指向第一阶段的 `epoch_2.pth`，`lr=1e-4`，再训 6–8 epoch。

> 注意：`frozen_stages` 是构造参数，训练中途改不了；两段式就是**两次 run**，不是同一 run 里切。

**预期精度**：ImageNet 预训练 VGG16 + 25k 猫狗，8 epoch 全量微调一般在 **97%–99%**；
只训 head（冻结卷积）也能到 96%–97%。**> 95% 是很有余量的目标**，不用刻意调。

### 7.4 `tools/train.py`

```python
import argparse

import compat  # noqa: F401  torch.load 补丁（torch>=2.6 读 mmengine ckpt 需要）
import vggnet.backbones.vgg  # noqa: F401  ★ 显式注册 VGGNet，别只依赖 custom_imports
from mmengine.config import Config, DictAction
from mmengine.runner import Runner


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("config")
    parser.add_argument("--work-dir", default=None)
    parser.add_argument("--launcher", choices=["none", "pytorch"], default="none")
    parser.add_argument("--cfg-options", nargs="+", action=DictAction)
    args = parser.parse_args()

    cfg = Config.fromfile(args.config)
    if args.cfg_options is not None:
        cfg.merge_from_dict(args.cfg_options)
    if args.work_dir is not None:
        cfg.work_dir = args.work_dir
    cfg.launcher = args.launcher

    Runner.from_cfg(cfg).train()


if __name__ == "__main__":
    main()
```

> **为什么用 `DictAction` 而不是 `eval`**：`DictAction` 会把 `--cfg-options optimizer.lr=0.001` 正确解析成嵌套
> 字典 `{"optimizer": {"lr": 0.001}}`；手写 `merge_from_dict({"optimizer.lr": 0.001})` 只会得到一个
> 名叫 `optimizer.lr` 的**顶层键**，配置根本不会变。
>
> **为什么入口要显式 `import vggnet.backbones.vgg`**：`custom_imports` 只在 `Runner.from_cfg` 里执行，
> `get_model` / 推理脚本都不会执行它；DDP 的 spawn 子进程也会重新跑入口脚本。显式 import 最稳。

### 7.6 常见失败

| 现象 | 原因 | 处理 |
| :--- | :--- | :--- |
| `loss: nan` | lr 太大（无 BN 的 VGG 敏感），或没加载预训练 | `lr=1e-4` 或更小，确认日志里有 `Load checkpoint from ...` |
| 第 1 epoch 只有 ~80% | 权重没加载（URL 写错 / 被 `init_cfg` 覆盖 / 配置里漏了 `load_from`） | 看启动日志前 20 行有没有加载成功的记录 |
| `AssertionError: The number of subfolders (2) doesn't match ... (1000)` | `classes` 没传 | `dataset=dict(classes=classes)` |
| `mat1 and mat2 shapes cannot be multiplied` | 输入不是 224（改了 crop 尺寸），或 `with_last_pool=False` | 数据管线最终必须是 224×224 |
| `KeyError: 'VGGNet' is not in the registry` | 注册没执行 / import 失败被吞 | 确认 `import vggnet.backbones.vgg` + `pip install -e .` |
| checkpoint 加载报 `UnpicklingError` | 5.5 的补丁没加 | `import compat` |
| `DataLoader worker ... exited unexpectedly`（Windows） | spawn + 中文路径 + 大内存 | 冒烟 `num_workers=0`；稳定后 4–8 |

### 8.2 配置（7.1 里已经写好）

`config/vgg16net_cats_dogs.py` 里是这段，**装了 tensorboard 才启用 backend**，没装也不影响训练：

```python
vis_backends = [dict(type="LocalVisBackend")]
```

> mmengine 的 `LoggerHook` 会自动把标量塞给 `runner.visualizer`（源码里就是
> `runner.visualizer.add_scalars`），所以**不用改 hook**，只要配上 backend 就有曲线。
> 事件文件写在 `work_dirs/vgg16net_cats_dogs/vis_data/` 下。
>
> ⚠️ config 里**不要写 `import tensorboard` 或 `from importlib.util import find_spec`**：
> 前者会把 module 对象塞进 Config，Runner 深拷贝时报 `cannot pickle 'module' object`；
> 后者会被 mmengine 的 config 机制变成 LazyObject，一调用就 `RuntimeError`。
> 用 `__import__("tensorboard")` 最稳（已验证）。

## Phase 9：实拍图推理（目标 4）

### 9.1 `tools/infer.py`

```python
import argparse

import compat  # noqa: F401  torch.load 补丁
import torch
from mmengine.config import Config
from mmengine.dataset import Compose
from mmengine.runner import load_state_dict
from mmpretrain import get_model
from mmpretrain.registry import TRANSFORMS

import vggnet.backbones.vgg  # noqa: F401  ★ 注册 VGGNet


def build_model(cfg, checkpoint):
    # get_model 需要「带 model 键的 Config」，把顶层 data_preprocessor 一起带进去
    model = get_model(Config(dict(model=cfg.model,
                                  data_preprocessor=cfg.data_preprocessor)))
    ckpt = torch.load(checkpoint, map_location="cpu", weights_only=False)
    load_state_dict(model, ckpt["state_dict"], strict=False)
    model.eval()
    return model


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("config")
    parser.add_argument("checkpoint")
    parser.add_argument("images", nargs="+")
    parser.add_argument("--topk", type=int, default=2)
    args = parser.parse_args()

    cfg = Config.fromfile(args.config)
    model = build_model(cfg, args.checkpoint)
    pipeline = Compose([TRANSFORMS.build(t) for t in cfg.test_pipeline])
    classes = cfg.classes

    for path in args.images:
        sample = pipeline(dict(img_path=path))
        # 单张图 → 手动组 batch（PackInputs 输出的是单样本）
        batch = dict(inputs=sample["inputs"].unsqueeze(0),
                     data_samples=[sample["data_samples"]])
        with torch.no_grad():
            pred = model.test_step(batch)[0]

        probs = pred.pred_score
        k = min(args.topk, len(probs))
        top = torch.topk(probs, k)
        print(f"\n{path}")
        for score, idx in zip(top.values.tolist(), top.indices.tolist()):
            print(f"  {classes[idx]:>4s}  {score:.4f}")


if __name__ == "__main__":
    main()
```
