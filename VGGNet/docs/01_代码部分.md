### 2.2 关键设计：3 层 FC 在 backbone 内部

```
ImageClassifier
├── data_preprocessor : ClsDataPreprocessor（归一化 + 可选 one-hot）
├── backbone          : VGG —— num_classes>0 时直接吐 (B, 1000) logits
├── neck              : None
└── head              : ClsHead（只算 loss / accuracy，没有 fc）
```

- `out_indices` 默认值随 `num_classes` 变：`num_classes > 0 → (5,)`（只要 logits，`5` 这个下标永远不会命中
  stage 循环，是个「不输出特征图」的哨兵值）；`num_classes <= 0 → (4,)`（第 5 个 stage 的特征图 7×7）。
- **为什么必须这样**：官方发布权重的键是 `backbone.classifier.0/3/6.weight`，FC 在 backbone 里才加载得上。
  如果你把 FC 拆到 head 里，权重键对不上，**目标 2 直接做不到**。
- **本次迁移学习要复用这个设计**：`num_classes=2` 时 VGG 内部只重建成 `Linear(4096, 2)`，前两个
  `Linear(25088,4096)`、`Linear(4096,4096)` 和全部卷积层都能吃官方权重。

- [ ] 2.2.1 能回答：教科书式（backbone 出特征 → GAP → LinearClsHead）为什么加载不了官方权重
- [ ] 2.2.2 能回答：猫狗 2 分类时，哪些层能复用官方权重、哪些必须重训

### 4.2 关键约束（写完逐条对照）

| # | 约束 | 不这么做会怎样 |
| :--- | :--- | :--- |
| 1 | 卷积一律 `kernel_size=3, stride=1, padding=dilation` | 输出尺寸对不上，weight 键名/形状全错 |
| 2 | **`bias=True`** | 无 bias 时 `state_dict` 直接少键，加载官方权重失败 |
| 3 | 通道 `64 * 2**i`（i<4），第 5 个 stage 恒 512 | 参数量对不上（差 0.01M 也算错） |
| 4 | 每个 stage 末尾 `MaxPool2d(2, 2, ceil_mode=ceil_mode)` | 224/32 = 7 不成立，FC 形状崩 |
| 5 | classifier 输入 `512*7*7 = 25088`（硬编码） | 输入不是 224 就报 `mat1 and mat2 shapes cannot be multiplied` |
| 6 | `num_classes=-1` 表示只做特征提取 | 会白建 123M 参数的 FC，且输出维度错 |

### 4.3 `range_sub_modules` 是什么

`features` 是扁平的 `nn.Sequential`，但 `forward` / `_freeze_stages` 要按 stage 操作，所以建层时记录每个 stage 在下标区间 `[start, end)`：

```
stage 0: [0, 3)   conv, conv, pool
stage 1: [3, 6)   conv, conv, pool
stage 2: [6, 10)  conv, conv, conv, pool
...
```

- [ ] 4.3.1 `num_modules = num_blocks + 1`（+1 是 pool）
- [ ] 4.3.2 `with_last_pool=False` 时既要 `pop` 层，又要让最后一个区间 `end -= 1`

### 4.4 单变体对齐：`tools/check_parity.py`

> ⚠️ **必须 `eval()`**。train 模式下 Dropout 随机置零、BN 用 batch 统计量，`diff` 永远不为 0。
> 建议**在 CPU 上跑对齐**：同权重、同输入、float32 逐位一致，结果就是严格的 `0.0`；
> 放到 GPU 上可能因 cuDNN 选算法出现 `1e-6` 级差异。

```python
import torch

from mmpretrain.models.backbones import VGG as OfficialVGG
from vggnet.backbones.vgg import VGG as MyVGG

a = OfficialVGG(16, num_classes=1000); a.eval()
b = MyVGG(16, num_classes=1000); b.eval()

sa, sb = a.state_dict(), b.state_dict()
assert set(sa) == set(sb), f"键不一致: 多={set(sb) - set(sa)} 少={set(sa) - set(sb)}"
assert all(sa[k].shape == sb[k].shape for k in sa), "有层形状不对"
print("keys:", len(sa))                      # VGG16 应为 32

b.load_state_dict(sa, strict=True)           # 官方权重直接灌进来

x = torch.randn(1, 3, 224, 224)              # ★ 同一个输入，别调两次 randn
with torch.no_grad():
    oa = a(x)[0]
    ob = b(x)[0]

print("max |diff| =", (oa - ob).abs().max().item())     # 期望 0.0
print("params(M)  = %.2f" % (sum(p.numel() for p in b.parameters()) / 1e6))
```

期望：`keys: 32`、`max |diff| = 0.0`、`params(M) = 138.36`。

> **不要写 `a = OfficialVGG(...).eval()`**：官方 `VGG.train()` 没有 `return self`，`.eval()` 会返回 `None`，
> 下一行就 `AttributeError: 'NoneType' object has no attribute 'state_dict'`。分两行写；你自己的实现要补 `return self`。

### 4.5 8 变体总验收：`tools/check_all_variants.py`

只对齐 VGG16 说明不了什么——`arch_settings` 抄错一个数字、`norm_cfg` 传错位置，单测 VGG16 都可能 `diff=0`。

```python
import torch

from mmpretrain.models.backbones import VGG as OfficialVGG
from vggnet.backbones.vgg import VGG as MyVGG

CASES = [(11, None), (13, None), (16, None), (19, None),
         (11, {"type": "BN"}), (13, {"type": "BN"}),
         (16, {"type": "BN"}), (19, {"type": "BN"})]

x = torch.randn(1, 3, 224, 224)              # ★ 所有变体共用同一个输入
for depth, norm_cfg in CASES:
    kw = dict(depth=depth, num_classes=1000, norm_cfg=norm_cfg)
    a, b = OfficialVGG(**kw), MyVGG(**kw)
    a.eval(); b.eval()                       # ★ 必须 eval
    sa, sb = a.state_dict(), b.state_dict()
    assert set(sa) == set(sb), f"depth={depth} 键不一致"
    assert all(sa[k].shape == sb[k].shape for k in sa), f"depth={depth} 形状不一致"
    b.load_state_dict(sa, strict=True)
    with torch.no_grad():
        diff = (a(x)[0] - b(x)[0]).abs().max().item()
    print(f"depth={depth:2d} type={'bn ' if norm_cfg else 'plain'} "
          f"params={sum(p.numel() for p in b.parameters()) / 1e6:7.2f}M diff={diff}")
```

### 4.6 四个必须知道的坑

1. **`init_cfg` 不能省**：没有 Kaiming / Constant(1) / Normal(0.01)，无 BN 的 VGG16 从零训练极易梯度爆炸。
   且 `init_cfg` 只有继承 `BaseModule` 并 `super().__init__(init_cfg)` 才生效。
2. **`train()` 记得 `return self`**：官方也漏了（见 4.4 的警告）。补上不影响权重对齐。
3. **`num_classes` 存在 backbone 里**：迁移学习时 backbone 的 `num_classes` 必须和数据类别数一致，
   否则 classifier 输出维度和标签对不上。
4. **`frozen_stages` 在构造时不生效**：冻结写在 `train()` 里，只有调用过 `model.train()` 之后参数才是
   `requires_grad=False`。Runner 训练前会自动 `model.train()`，所以训练没问题；手动构造后立刻检查会以为没生效。

**验收**：4.4 的 `0.0` + 4.5 的 8 行，全绿 → 目标 1 完成。

## Phase 5：加载官方预训练权重（目标 2）

### 5.1 三条路，别用错

| 方式 | 在哪生效 | 适用场景 | 注意 |
| :--- | :--- | :--- | :--- |
| `get_model("vgg16_8xb32_in1k", pretrained=True)` | 推理 / 结构验证 | 确认权重能跑通、做官方基线 | 自动下载 ~0.53GB |

三条路**不要同时用**：`Runner` 里先执行 `init_cfg`，再执行 `load_from`，后者会覆盖前者。

```python
       "vgg16_batch256_imagenet_20210208-db26f1a5.pth")

        neck=None,
        head=dict(type="ClsHead",
                  loss=dict(type="CrossEntropyLoss", loss_weight=1.0),

    ),

))
```

### 5.4 1000 类 → 2 类：尺寸不匹配是**预期行为**

猫狗只有 2 类，`classifier.6` 必须重建为 `Linear(4096, 2)`。用 `load_from` 加载 1000 类权重时，
mmengine 会打一条警告然后**跳过这两个键**，其余 30 个键照常加载（本机实测日志）：

```
The model and loaded state dict do not match exactly

size mismatch for backbone.classifier.6.weight: copying a param with shape torch.Size([1000, 4096]) from checkpoint, the shape in current model is torch.Size([2, 4096]).
size mismatch for backbone.classifier.6.bias: copying a param with shape torch.Size([1000]) from checkpoint, the shape in current model is torch.Size([2]).
```

- 看到这两行 **不要慌，也不要改 `strict=True`**——这正是你要的效果：
  卷积 + 前两层 FC 全部复用，最后一层随机初始化（`Normal(std=0.01)`）等训练。

### 5.5 必装补丁：torch ≥2.6 读 mmengine checkpoint 会报错

`torch.load` 从 2.6 起默认 `weights_only=True`，而 mmengine 0.10.7 存盘时带了 `HistoryBuffer`：

```
_pickle.UnpicklingError: Weights only load failed ...
WeightsUnpickler error: Unsupported global: GLOBAL mmengine.logging.history_buffer.HistoryBuffer
```

**影响**：断点续训（`--resume`）、`load_from` 指向自己训出来的 ckpt、`Runner.test()` 全部失败（本机已实测）。
之前 `load_from` 官方权重没问题，是因为官方 ckpt 里没有这些对象。

新建 `tools/compat.py`（三个入口脚本顶部 `import compat`）：

```python
"""torch>=2.6 的 torch.load(weights_only=True) 与 mmengine 0.10.7 checkpoint 不兼容的补丁。"""
import torch

_original_load = torch.load


def _patched_load(*args, **kwargs):
    kwargs.setdefault("weights_only", False)   # 只对可信的本地/官方 ckpt
    return _original_load(*args, **kwargs)


torch.load = _patched_load
```

> 为什么不用 `torch.serialization.add_safe_globals`：实测只加 `HistoryBuffer` 仍然失败（checkpoint 里还有别的对象），
> 逐个加太脆。`weights_only=False` 是官方文档给出的方案，只要**只加载自己训的 / 官方发布的 ckpt** 就安全。

```python
import torch.nn as nn
from mmcv.cnn import ConvModule
from mmengine.utils.dl_utils.parrots_wrapper import _BatchNorm

from mmpretrain.models.backbones.base_backbone import BaseBackbone
from mmpretrain.registry import MODELS


def make_vgg_layer(in_channels, out_channels, num_blocks, conv_cfg=None,
                   norm_cfg=None, act_cfg=dict(type="ReLU"), dilation=1,
                   with_norm=False, ceil_mode=False):
    """一个 VGG stage：num_blocks 个 3x3 卷积 + 一个 2x2 MaxPool。"""
    layers = []
    for _ in range(num_blocks):
        layers.append(
            ConvModule(
                in_channels=in_channels,
                out_channels=out_channels,
                kernel_size=3,
                dilation=dilation,
                padding=dilation,
                bias=True,           # 原版 VGG 卷积带 bias
                conv_cfg=conv_cfg,
                norm_cfg=norm_cfg,   # 传了 BN 就是 VGG16-BN
                act_cfg=act_cfg))
        in_channels = out_channels
    layers.append(nn.MaxPool2d(kernel_size=2, stride=2, ceil_mode=ceil_mode))
    return layers


@MODELS.register_module("VGGNet")
class VGG(BaseBackbone):
    """从零复现的 VGG backbone。"""

    arch_settings = {
        11: (1, 1, 2, 2, 2),
        13: (2, 2, 2, 2, 2),
        16: (2, 2, 3, 3, 3),
        19: (2, 2, 4, 4, 4),
    }

    def __init__(self, depth, num_classes=-1, num_stages=5,
                 dilations=(1, 1, 1, 1, 1), out_indices=None,
                 frozen_stages=-1, conv_cfg=None, norm_cfg=None,
                 act_cfg=dict(type="ReLU"), norm_eval=False,
                 ceil_mode=False, with_last_pool=True,
                 init_cfg=[dict(type="Kaiming", layer=["Conv2d"]),
                           dict(type="Constant", val=1., layer=["_BatchNorm"]),
                           dict(type="Normal", std=0.01, layer=["Linear"])]):
        super().__init__(init_cfg)
        if depth not in self.arch_settings:
            raise KeyError(f"invalid depth {depth} for vgg")
        assert 1 <= num_stages <= 5
        assert len(dilations) == num_stages

        self.stage_blocks = self.arch_settings[depth][:num_stages]
        self.num_classes = num_classes
        self.frozen_stages = frozen_stages
        self.norm_eval = norm_eval

        if out_indices is None:
            out_indices = (5,) if num_classes > 0 else (4,)
        assert max(out_indices) <= num_stages
        self.out_indices = out_indices

        self.in_channels = 3
        start_idx = 0
        vgg_layers = []
        self.range_sub_modules = []
        for i, num_blocks in enumerate(self.stage_blocks):
            num_modules = num_blocks + 1           # +1 是 pool
            end_idx = start_idx + num_modules
            out_channels = 64 * 2**i if i < 4 else 512
            vgg_layers.extend(
                make_vgg_layer(
                    self.in_channels,
                    out_channels,
                    num_blocks,
                    conv_cfg=conv_cfg,
                    norm_cfg=norm_cfg,
                    act_cfg=act_cfg,
                    dilation=dilations[i],
                    ceil_mode=ceil_mode))
            self.in_channels = out_channels
            self.range_sub_modules.append([start_idx, end_idx])
            start_idx = end_idx

        if not with_last_pool:
            vgg_layers.pop(-1)
            self.range_sub_modules[-1][1] -= 1
        self.module_name = "features"
        self.add_module(self.module_name, nn.Sequential(*vgg_layers))

        if num_classes > 0:
            self.classifier = nn.Sequential(
                nn.Linear(512 * 7 * 7, 4096),
                nn.ReLU(True),
                nn.Dropout(),
                nn.Linear(4096, 4096),
                nn.ReLU(True),
                nn.Dropout(),
                nn.Linear(4096, num_classes),
            )

    def forward(self, x):
        outs = []
        vgg_layers = getattr(self, self.module_name)
        for i in range(len(self.stage_blocks)):
            for j in range(*self.range_sub_modules[i]):
                x = vgg_layers[j](x)
            if i in self.out_indices:
                outs.append(x)
        if self.num_classes > 0:
            x = x.view(x.size(0), -1)
            x = self.classifier(x)
            outs.append(x)
        return tuple(outs)

    def _freeze_stages(self):
        vgg_layers = getattr(self, self.module_name)
        for i in range(self.frozen_stages):
            for j in range(*self.range_sub_modules[i]):
                m = vgg_layers[j]
                m.eval()
                for param in m.parameters():
                    param.requires_grad = False

    def train(self, mode=True):
        super().train(mode)
        self._freeze_stages()
        if mode and self.norm_eval:
            for m in self.modules():
                if isinstance(m, _BatchNorm):
                    m.eval()
        return self   # 官方实现漏了这行
```
